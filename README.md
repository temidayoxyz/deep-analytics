# dsh-deep-analytics

Deep Analytics is a DeepSeek Harness plugin that adds a full-fledged analytics
dashboard to the left sidebar. It surfaces usage, activity and performance
metrics derived from your actual conversation data: total turns, steps,
lifetime tokens, average tok/s, cache hit rate, peak tokens, longest task
time, current and longest day streaks, a GitHub-style task activity map,
models used, installed plugins, and contextual insights.

The page is accessible from the sidebar as "Analytics" and is placed after
"Plugins".

## Install

Installed as a bundle in a DeepSeek Harness profile.

## Development

```
pnpm install
pnpm run build
pnpm run typecheck
```
